# Security

Report vulnerabilities through GitHub Security Advisories on
[blazium-games/blazium-subagents](https://github.com/blazium-games/blazium-subagents/security/advisories/new).

Do not file a public issue for a security report.

This repository is agent roster text. Agents must not invent `blazium-cli`
verbs, enable `allow_eval` / `remote_control_exec` unless the user asks, or
mix editor MCP (`:6506`), game MCP (`:6507`), remote_control (`:6508`), and
Hub (`:39218`).
